## Context

`apps/site` 尚不存在，根 workspace 已覆盖 apps/* 并提供共享检查。官网内容范围已确认；安装包实际发布信息由发布 change 提供。

## Goals / Non-Goals

**Goals:** 纯静态产物，应用独立构建和部署，下载入口与实际发布状态一致。

**Non-Goals:** 不加入官网在线登录、RAG、支付、服务端渲染或没有复用消费者的组件包。

## Decisions

### 独立静态应用

使用已确定的 Vite、React 19 与 Astryx，应用 tsconfig、Vite 配置和构建依赖留在 apps/site，复用根静态检查。根 build 收集 site/dist，客户端仍独立输出 out；不引入 Astro、Next.js 或 Electron 依赖。

页面按产品介绍、能力范围、下载、使用说明和 FAQ 组织，页面私有组件留在页面模块。只使用实际需要的组件与语义 token，不复制客户端认证或主题偏好系统。

### 发布内容配置

下载版本、支持平台和 HTTPS 地址通过明确发布配置提供。没有有效发行配置时显示尚未开放下载的状态，不指向示例地址；正式上线验证地址与安装包版本一致。静态站点不依赖 API 存活，不收集账号或咨询正文。

## Risks / Trade-offs

- 宣传文案超出实际能力 → 按 v1 范围审核，区分条款依据和咨询范围。
- 静态下载地址失效 → 发布阶段验证目标产物和平台，部署替换时同步配置。
- 应用依赖相互污染 → 验证 site 依赖树无 Electron、客户端安装包无 site 产物。

## Migration Plan

创建实际可展示的官网及独立构建入口，验证本地预览和静态产物。托管可直接替换静态版本，回退到上一个产物及对应下载配置；不涉及业务数据库。
