## Purpose

提供可独立静态托管的产品介绍与桌面分发入口，让访问者了解保险咨询的实际能力、依据与使用范围，并能按真实发布状态取得受支持安装包，官网访问不依赖桌面应用或问答服务运行。

## ADDED Requirements

### Requirement: 产品范围与使用信息

官网 MUST 提供产品介绍、能力及咨询范围、使用说明和 FAQ，信息与 v1 实际能力一致，不宣称未支持的投保、保单或付费能力。

#### Scenario: 浏览官网

- **WHEN** 访问者打开官网
- **THEN** 可找到能力范围、依据说明和使用入口

#### Scenario: 范围核对

- **WHEN** 访问者查看 FAQ 与介绍
- **THEN** 内容不将咨询服务描述成已实现的在线投保或保单管理

### Requirement: 真实下载状态

下载入口 MUST 明确支持平台与发布版本，仅在有效发布配置存在时提供真实 HTTPS 下载地址，无有效发行配置时不可提供示例或虚假可用链接。

#### Scenario: 有效发行

- **WHEN** 已配置受支持 macOS 安装包地址与版本
- **THEN** 显示相应下载入口与版本

#### Scenario: 尚未发行

- **WHEN** 未配置有效安装包
- **THEN** 显示未开放下载状态，不跳转示例域名

### Requirement: 静态独立与产物隔离

官网 MUST 能独立构建、预览和静态部署，访问不依赖 API 存活；官网依赖不含 Electron，客户端安装包不包含官网产物。

#### Scenario: 服务离线

- **WHEN** 问答 API 暂不可用
- **THEN** 静态介绍、FAQ 和下载信息仍可浏览

#### Scenario: 独立构建

- **WHEN** 分别构建官网和客户端
- **THEN** 输出各自应用产物，依赖及分发文件互不混入
