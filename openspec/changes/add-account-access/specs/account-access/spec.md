## Purpose

为普通用户和管理员提供受控账号及可撤销的登录会话，使后续资料和问答访问能够依据身份、角色和资源归属执行权限检查，登录续期、凭据失效及设备吊销具有明确的外部行为。

## ADDED Requirements

### Requirement: 受控账号管理

系统 MUST 仅通过受运维权限保护的入口创建、停用或重置账号，角色固定普通用户和管理员；重复初始化首个管理员不得覆盖现有账号与密码。

#### Scenario: 重复初始化

- **WHEN** 首个管理员已经存在时再次初始化
- **THEN** 原账号、角色和密码保持不变

#### Scenario: 公开提权

- **WHEN** 普通用户通过公开接口尝试注册管理员或改变角色
- **THEN** 操作被拒绝

### Requirement: 登录与凭据保护

系统 MUST 使用规范化邮箱和密码登录，保存安全密码哈希和不透明令牌哈希，原始密码与令牌不进入日志、公开记录或持久业务数据。

#### Scenario: 正确登录

- **WHEN** 有效账号提交正确密码
- **THEN** 返回有限期访问及刷新凭据和当前账号身份

#### Scenario: 登录失败

- **WHEN** 账号不存在、密码错误或账号停用
- **THEN** 返回统一可识别登录失败，不披露账号是否存在

### Requirement: 刷新轮换与重放检测

系统 MUST 对刷新令牌设置有效期，在续期时原子轮换，并检测已使用刷新凭据的重放；访问凭据过期与刷新会话失效必须可区分。

#### Scenario: 有效续期

- **WHEN** 有效设备会话使用当前刷新令牌
- **THEN** 返回新凭据，旧刷新令牌不能继续正常续期

#### Scenario: 旧令牌重放

- **WHEN** 已轮换的刷新令牌被再次使用
- **THEN** 该设备会话被撤销，返回稳定失效错误

### Requirement: 账号和设备撤销

系统 MUST 支持退出、设备吊销、账号停用及密码重置的会话撤销，被撤销凭据不可继续访问保护资源。

#### Scenario: 设备退出

- **WHEN** 用户退出当前设备会话
- **THEN** 该设备访问和刷新凭据均失效

#### Scenario: 密码重置

- **WHEN** 管理员重置账号密码
- **THEN** 相应已有会话失效，新密码可用于重新登录

### Requirement: 角色与资源归属

保护接口 MUST 在服务端独立检查身份、角色和资源归属，不能依赖客户端隐藏菜单或路由守卫。

#### Scenario: 跨账号访问

- **WHEN** 用户请求另一个账号的会话、运行或来源
- **THEN** 返回不可访问结果，不泄露资源内容

#### Scenario: 普通用户管理资料

- **WHEN** 普通用户调用管理员管理接口
- **THEN** 返回权限不足，不产生管理副作用
