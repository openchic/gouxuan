## Context

依赖基础存储与账号。知识库管理当前没有实现；本 change 将资料推进至已审核、索引可查询的冻结候选。发布评测由 RAG change 完成，不形成反向依赖。

## Goals / Non-Goals

**Goals:** 各处理阶段可观测、有限执行、显式审核、幂等重试，候选内容及配置可追溯。

**Non-Goals:** 不发布未评测候选，不实现 OCR、网页抓取、批量审批、独立向量服务或专门评测平台。

## Decisions

### 上传与受限解析

只接收文本 PDF / UTF-8 Markdown，初值 20MB、500 页、100 万提取字符。保存标题、来源、条款或咨询知识类型、产品和文档版本、生效日期、使用展示权限、上传人及内容哈希。来源地址仅作元数据，不自动抓取。

原始对象确认写入后，短事务登记资料与任务；上传键按账号隔离，重复请求恢复原结果，同键不同载荷冲突。对象与数据库无法同事务，通过确认、关联和过期未关联对象清理闭环，不能将“文件存在”视为任务成功。

pypdf 在受限子进程执行，内存 512MiB、60 秒；规范化文本保留页码及条款定位。管理员通过原文对照预览审核后才构建索引，等待审核不占 worker。

### 资料队列与阶段状态

`worker.py` 提供资料 worker 实际使用的入口，问答 worker 由 RAG change 扩充。Postgres 短事务行锁领取任务，租约代次与心跳管理执行归属；每次阶段写入检查代次、有效期和当前状态，网络调用期间不持有事务。

状态为待处理、解析中、待审核、索引构建中、评测中、待发布、已发布、失败；本 change 实现至索引和冻结候选，评测之后的实际处理由后续 change 接入。索引阶段预算 30 分钟，已确认安全的临时错误最多自动重试一次；超限、租约过期或供应商结果不明明确失败。管理员重试当前失败阶段，在同事务增加执行代次并入队，复用确认产物，不重试未知模型副作用。

### 索引与完整 manifest

摄取分块在 `ingest.py`，保留文本、页码、条款和版本。jieba 搜索分词、保险词典、产品别名与 Postgres simple 词法索引配套，向量以固定 embedding 模型与维度写入 pgvector。

候选从当前整库 manifest 复制，初始为空；新增保留其他文档，更新只替换显式指定版本。索引产物、分块、词法与 embedding 配置完成后冻结完整 manifest。文档版本不可变；配置或集合变化产生新候选，不修改已冻结版本。

### 模型网关与计量

在 `model_gateway.py` 接入实际 embedding 消费者，统一调用超时、供应商请求 ID、配置版本及用量；不预建没有调用方的 adapter。资料调用关联操作者与任务；生成、摘要、rerank、评测由 RAG change 增加实际消费者。

用量记录按真实调用 ID 唯一，区分已确认和待核对，保留已知单位及状态，失败和取消也计量，迟到记录不能恢复任务内容。记录不含正文或密钥，30 天保留。钱包与账务随 v2 创建。

## Risks / Trade-offs

- 对象写入与元数据提交失败 → 原结果幂等恢复与未关联对象清理，验证每个失败点。
- 资料 worker 超限或失去租约 → API 定期收尾过期阶段，阻止旧代次写入。
- 词法与向量配置混用 → 完整 manifest 绑定配置，构建阶段做一致性检查。

## Migration Plan

在基础迁移上增资料、阶段队列、候选、分块、索引与用量表，开发 Compose 增独立资料 worker。先用合成 PDF / Markdown 验证，首次真实入库前必须提供授权元数据及实际 embedding 配置。回退停止领取新任务，保留原始资料和已确认产物，不清理已被 manifest 引用的数据。
