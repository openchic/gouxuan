## Purpose

将管理员手动上传的授权文本资料转换为可审核、可追溯且可检索的不可变版本，通过有限执行和阶段重试形成冻结的完整候选语料，为后续内部评测及正式整库发布提供可靠输入。

## ADDED Requirements

### Requirement: 管理员上传与输入限制

系统 MUST 仅允许管理员上传文本 PDF 或 UTF-8 Markdown，校验格式、大小、页数、字符量与可定位性，保存来源、产品版本、权限、上传人和内容哈希。

#### Scenario: 有效上传

- **WHEN** 管理员上传符合限制的资料并补齐元数据
- **THEN** 返回可追溯资料版本与处理任务

#### Scenario: 不支持或超限

- **WHEN** 上传扫描件、不合法编码或超出配置上限的文件
- **THEN** 明确拒绝或标记处理失败，不继续建立可发布索引

### Requirement: 上传登记幂等

系统 MUST 在原始对象确认保存后原子登记资料与任务，并按账号及上传幂等键恢复同一结果；同键不同载荷返回冲突，未关联对象可按期限清理。

#### Scenario: 响应丢失后重试

- **WHEN** 管理员以相同键和载荷再次上传
- **THEN** 返回原资料与任务 ID，不重复登记

#### Scenario: 键载荷冲突

- **WHEN** 相同键对应不同文件或元数据
- **THEN** 返回冲突，不覆盖原资料

### Requirement: 人工审核与可定位预览

系统 MUST 提供解析正文与原文定位预览，在管理员审核通过后才允许构建索引，审核等待不得占用处理执行并发。

#### Scenario: 待审核

- **WHEN** 解析完成但管理员尚未通过审核
- **THEN** 资料可预览而不能进入可用候选索引

#### Scenario: 审核通过

- **WHEN** 管理员核对原文和定位后通过审核
- **THEN** 进入后续索引处理，保留审核记录

### Requirement: 有限处理与独立任务

资料处理 MUST 独立于问答执行和客户端页面生命周期，受阶段耗时、解析内存、并发及租约限制；超限或执行归属失效时明确失败，旧执行结果不能覆盖新状态。

#### Scenario: 页面离开

- **WHEN** 管理员关闭资料页面
- **THEN** 服务端处理继续并可通过任务 ID 查询

#### Scenario: 超限或过期

- **WHEN** 解析超过资源限制或阶段租约过期
- **THEN** 任务失败并显示原因，迟到阶段写入被拒绝

### Requirement: 安全阶段重试

系统 MUST 仅对已确认安全的临时错误自动重试至配置上限；管理员显式重试当前失败阶段时使用幂等键和新执行代次，并复用已确认产物。

#### Scenario: 显式重试

- **WHEN** 管理员对失败索引阶段以相同重试键重复请求
- **THEN** 只建立一次新阶段执行，不重新处理已确认的原始资料

#### Scenario: 未知模型结果

- **WHEN** 供应商可能已执行而结果不明确
- **THEN** 不盲目重复调用，任务失败并保留已知及待核对用量

### Requirement: 索引配置与冻结完整候选

系统 MUST 保留不可变文档版本、原文定位与访问元数据，索引绑定一致的分块、词法和 embedding 配置；候选冻结完整文档集合与索引产物，新增保留其他文档，更新只替换明确版本。

#### Scenario: 新增资料

- **WHEN** 在含多份文档的当前集合上加入已审核新资料
- **THEN** 候选包含全部保留文档和新版本，索引配置一致

#### Scenario: 更新或配置变化

- **WHEN** 管理员替换指定文档或更换索引配置
- **THEN** 建立新候选并冻结完整集合，不修改已冻结版本
