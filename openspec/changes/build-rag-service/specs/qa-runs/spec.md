## Purpose

让账号会话和问答运行具备持久、幂等且可恢复的生命周期，保障首次提交、最新一轮重跑、取消及删除的原子状态，流式连接中断不会重复问答，失去执行归属后的结果不能重新写回内容。

## ADDED Requirements

### Requirement: 原子提交与账号幂等

问答提交 MUST 在认证后原子创建会话、用户消息、运行、回答候选及任务，并保存按账号隔离的幂等结果；重复同键同载荷返回相同 ID，同键不同载荷冲突，失败不留孤立数据。

#### Scenario: 事务失败

- **WHEN** 创建过程中任一必要写入失败
- **THEN** 所有本次对象均回滚，不留下孤立消息或运行

#### Scenario: 并发重复及响应丢失

- **WHEN** 同账号以原键并发或重新提交相同载荷
- **THEN** 返回相同会话、消息、运行和候选 ID，运行结束后也不重新创建

### Requirement: 最新一轮重跑与生效关系

重跑 MUST 只针对最新用户消息且不重复保存该消息；本轮上下文截止于当前问题之前。新候选核验并完成后才切换生效回答，失败或取消保留原回答。

#### Scenario: 重跑成功

- **WHEN** 最新一轮新候选通过终态核验
- **THEN** 切换该轮生效回答，旧候选保留可追溯但不重复进入会话历史

#### Scenario: 重跑失败

- **WHEN** 新候选失败或取消
- **THEN** 原生效回答不被覆盖，后续上下文不包含失败预览

### Requirement: 运行限制与执行预算

系统 MUST 检查配置的请求频率、排队长度、账号活动运行和模型并发限制，同会话最多一个排队或执行运行；本次执行共享总预算并固定会话修订、语料及模型配置。

#### Scenario: 活动运行冲突

- **WHEN** 当前会话已有排队或执行运行
- **THEN** 新提交或重跑被拒绝且不新增消息

#### Scenario: 预算耗尽

- **WHEN** 执行和安全重试共用预算已耗尽
- **THEN** 明确失败收尾，保留实际用量，不继续无限调用

### Requirement: 独立执行和归属隔离

运行 MUST 独立于客户端流连接执行，内容及进度写入仅接受当前有效执行归属；执行中断明确失败，由用户重跑，不能自动续跑可能产生模型副作用的执行。

#### Scenario: SSE 断线

- **WHEN** 客户端断开事件连接而未取消
- **THEN** 仍有效运行继续执行并可查询状态

#### Scenario: 租约过期迟到

- **WHEN** 旧 worker 失去执行归属后写进度或结果
- **THEN** 写入被拒绝，过期执行标失败，未领取排队任务仍可正常领取

### Requirement: 唯一终态与显式取消

运行 MUST 仅进入一次完成、失败或取消终态，停止操作发起服务端取消而不是仅断开连接；取消及删除后迟到结果不能恢复内容，最小用量补录不改变终态。

#### Scenario: 取消与完成竞争

- **WHEN** 取消和核验完成同时尝试收尾
- **THEN** 仅一个终态生效，之后无法写回被拒绝的候选

#### Scenario: 用户停止

- **WHEN** 用户明确取消活动运行
- **THEN** 运行进入可查询的取消状态，模型流被通知关闭，已产生用量保留

### Requirement: 公共事件的持久顺序与恢复

公共事件 MUST 携带运行 ID 和递增序号，每条传输载荷为完整 JSON；权威消息快照在完成事件之前提交，文本流结束不代表完成。重连只恢复事件或状态，不重复提交。

#### Scenario: 正常完成

- **WHEN** 最终回答持久化并核验通过
- **THEN** 先输出权威 MESSAGES_SNAPSHOT 再输出 RUN_FINISHED，TEXT_MESSAGE_END 不提前确认运行

#### Scenario: 事件过期

- **WHEN** 客户端恢复时所需事件超过保留期
- **THEN** 读取运行状态与权威历史恢复，不重建问答

#### Scenario: 事件重放

- **WHEN** 客户端按已确认序号恢复连接
- **THEN** 只处理后续序号，重复事件可按运行和序号去重

### Requirement: 受权历史与缓存 ID 核对

系统 MUST 提供受账号归属保护的会话和消息游标分页、运行状态与来源查询，并逐项核对最多 100 个缓存会话 ID 的可访问状态及当前修订。

#### Scenario: 分页不代表删除

- **WHEN** 会话没有出现在某页最近列表
- **THEN** 不会因此被报告删除，批量核对仍返回真实状态

#### Scenario: 跨账号 ID

- **WHEN** 批量核对包含另一个账号的 ID
- **THEN** 返回不可访问且不披露内容或他人修订

### Requirement: 删除与保留

会话删除 MUST 撤销活动执行，清理摘要、消息、引用和公共事件，并持久记录删除清单，ID 不复用；用量只保留最小字段，活动运行及可回滚语料引用的资料不能清理。

#### Scenario: 删除后迟到事件

- **WHEN** 会话已删除而旧执行继续发送结果
- **THEN** 内容和事件不能重新创建，删除状态可供客户端核对

#### Scenario: 清理被引用资料

- **WHEN** 资料仍被活动运行或可回滚版本使用
- **THEN** 资料及索引保留，历史自包含引用不受在线索引清理影响
