## Context

依赖前三个服务 change，复用冻结候选、账号、数据库和模型计量。当前没有会话、问答 worker 或公共事件。实现按 [PLAN.md](../../../PLAN.md) 的模块化单体和预算初值完成，不拆独立微服务。

## Goals / Non-Goals

**Goals:** 回答依据、运行归属和终态可追溯；首批候选可独立评测发布；预览、核验与生效回答明确区分。

**Non-Goals:** 不自动续跑执行中断，不引入持久 LangGraph checkpoint、无限反思、计费表或在线评测平台。

## Decisions

### 检索与有界质量流程

`retrieval.py` 使用一致分词与 query embedding，在绑定 manifest 内限定产品、版本、有效状态与权限；词法和精确向量召回通过 RRF 融合与 rerank 后补完整条款上下文。不引入 ANN 或 Qdrant，先用实际过滤场景验证延迟和召回。

`qa.py` 使用 LangGraph 管理理解、按需摘要、检索、证据检查、生成、一次修订与终止。检索最多两轮含首次，修订最多一次，总预算初值 90 秒。程序检查引用归属及版本，模型辅助核对支持程度；无证据、事实缺失或来源冲突不产生无依据确定结论。资料是证据，不作为指令；区分条款与咨询原则。

### 自动摘要

历史超过输入分配预算才复用生成模型摘要，每次运行最多一次、10 秒、512 输出 token，共享运行预算与计量。默认保留最近两轮完整生效原文，当前问题及必要证据优先。

会话仅保存一份摘要、覆盖消息 ID 与摘要配置版本；摘要保留主题、用户事实和待解问题，事实携带原 userMessageId 并回查，较新说明优先。摘要和旧模型回答都不能充当保险证据。重跑历史截止于当前问题之前；覆盖范围无效时重建。写回检查会话修订、删除及执行租约。失败保留旧有效摘要并使用预算内近期原文，必要事实不足时追问。

### 提交、重跑与执行事务

`execution.py` 在短事务锁定账号及已有会话，校验归属、修订和限制，原子保存会话、用户消息、运行、回答候选、队列任务和账号幂等结果。唯一约束及事务内复查保证并发重复键恢复相同 ID，同键不同载荷冲突。每会话一个活动运行，每账号两个，提交初值每分钟十次。

重跑只允许最新用户消息，复用其 ID，不把旧回答或失败预览送入本轮上下文；创建时固定会话修订、corpusReleaseId、模型和预算配置。通过核验的终态事务保存正文与引用、切换生效回答、写最终公共事件；失败或取消保留原回答。

问答 worker 与资料 worker 为同一应用镜像中的独立进程。领取使用短事务 SKIP LOCKED，LangGraph 状态在内存；所有进度、事件与最终内容写入检查租约代次、有效期、运行仍执行且会话未删除。取消、删除或终态使租约失效。API 定期将过期执行和预算耗尽标为失败，执行中断不重新入队；未领取排队任务正常执行。断开 SSE 不取消运行，用户停止才发取消。

### 结构化预览与公共事件

模型原生 JSON Schema 流经 JsonOutputParser 提取部分 answer 增量；部分解析仅用于预览，完整原始文本必须严格 JSON 与 Pydantic 校验，不能把解析器补齐结果当最终成功。

服务端转换并持久化 AG-UI 公共事件。每条 SSE data 是完整 JSON，带 runId 和连续递增序号；正文预览、阶段与终态均受执行守卫。最终正文、引用、权威 `MESSAGES_SNAPSHOT` 与 `RUN_FINISHED` 同事务提交后发送；`TEXT_MESSAGE_END` 只结束文本流。取消与失败明确报告，终态只提交一次，不暴露内部推理、prompt 或修订草稿。

重连按持久化序号重放，事件终态后保留 24 小时；过期后状态与权威消息恢复，不重新提交。用量由真实模型调用 ID 幂等记录，供应商结果未知不盲重试；终态后可补录最小迟到用量，不能写回内容。

### 候选评测与整库发布

内部入口显式指定候选 manifest 并复用问答工作流，检查审核、索引和配置，不依赖普通问答的已发布就绪条件。结果绑定 manifest、生成与 rerank、prompt、预算及 golden 版本，管理员人工复核结论与限制条件后允许发布；严重引用或无依据结论缺陷必须修复。

发布短事务比较当前指针与候选基准，冲突时重新生成候选并评测；回滚切换完整旧 manifest。已提交运行固定原版本。公开问答不可使用候选，空库仍允许账号及知识库路径。

### 历史、删除与保留

列表及消息游标分页；批量核对最多 100 个缓存会话 ID，逐项返回可访问状态与修订，不泄露他人内容。引用持久化标题、原文、定位、来源及版本，独立于 chunk 生命周期。

删除事务撤销租约并清理摘要、消息、引用和公共事件，写独立持久删除清单供恢复重放，ID 不复用。用量保留最小字段；仍被活动运行或可回滚 manifest 使用的资料和索引不得清理。清理入口在本 change 实现，部署调度和恢复验证在发布 change 完成。

## Risks / Trade-offs

- 全量消息快照随历史增长 → 遵守已确认事件契约并测量负载，不擅自变更为另一事件协议。
- 供应商执行结果未知 → 标待核对用量，必要生成失败收尾，不盲目重发。
- 取消与完成竞态 → 唯一终态事务和租约守卫，测试删除、超时及迟到写入。
- 初始实际模型和语料未提供 → 合成 fixture 验证逻辑，真实质量门禁由发布阶段落实。

## Migration Plan

新增会话、消息候选、生效关系、摘要、运行、问答队列、事件、评测与发布记录及删除清单；接入开发问答 worker。先验证合成候选评测、首发与 API 闭环，再真实联调。回退停止新提交、收尾活动运行、恢复兼容镜像和完整语料指针；不通过删除历史或幂等记录回退。
