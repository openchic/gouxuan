## Purpose

将 v1 的功能闭环转换为可公开运行与分发的版本，通过可重复的契约检查、真实语料和模型质量验收、完整部署及恢复演练验证运行边界，并以已签名公证和安装验证的产物提供真实官网下载安装。

## ADDED Requirements

### Requirement: 锁定依赖与契约检查

持续集成 MUST 覆盖各栈及其共享配置和契约依赖，以锁定依赖构建；OpenAPI、客户端生成类型或代码不一致时失败，并验证真实数据库迁移和集成行为。

#### Scenario: 契约漂移

- **WHEN** 修改公开接口后没有同步生成文件
- **THEN** 相关 CI 失败，不能将漂移版本报告为通过

#### Scenario: 共享依赖变更

- **WHEN** 锁文件、根脚本或共享检查配置改变
- **THEN** 受影响的各栈检查被触发并使用锁定依赖

### Requirement: 完整开发及生产启动

发布 MUST 提供可重复的基础存储、迁移、管理员初始化、API 与两类独立 worker 启动顺序，进程共享兼容版本且不自行迁移；生产不加载开发热重载或源码挂载。

#### Scenario: 全新部署

- **WHEN** 从空库按部署步骤启动
- **THEN** 迁移完成后可初始化管理员，登录并处理首批资料，发布后普通问答可用

#### Scenario: 迁移失败

- **WHEN** 一次迁移任务失败
- **THEN** 依赖进程不能以不兼容结构正常提供业务

#### Scenario: 生产配置

- **WHEN** 检查实际生产配置合并结果
- **THEN** 没有开发 reload 或本地源码挂载，两类 worker 独立运行

### Requirement: 真实资料模型与质量验收

对外发布 MUST 使用授权真实语料、固定实际模型和版本化私有 golden，人工复核结论及限制条件，覆盖无证据、冲突、追问、长会话摘要、事实更正和降级；合成结果不能替代上线证据。

#### Scenario: 真实验收

- **WHEN** 实际模型在固定候选和评测集上运行
- **THEN** 产生可追溯报告与人工结论，严重错误引用或无依据结论必须修复

#### Scenario: 输入缺失

- **WHEN** 资料权限、模型配置或私有样本尚未提供
- **THEN** 相应验收保持未完成，不宣布可以对外上线

### Requirement: 流式入口及运行负载

生产 MUST 提供 HTTPS、流心跳和无缓冲传输，按配置限制问答、资料与模型并发，并验证目标负载的队列、阶段耗时、失败及实际用量。

#### Scenario: 真实流式连接

- **WHEN** 用户通过生产 HTTPS 入口提问
- **THEN** 正文增量及时可见，断线可恢复而不重复提交

#### Scenario: 并发限制

- **WHEN** 提交达到配置并发或运行限制
- **THEN** 拒绝或排队行为符合契约，不无限占用模型资源

### Requirement: 备份删除恢复与保留

发布 MUST 验证数据库及原始资料每日备份和 7 天保留，恢复时重放独立删除清单，检查整库回滚及配置的事件用量清理；受活动运行或可回滚版本保护的资料不得清理。

#### Scenario: 备份恢复

- **WHEN** 在独立环境从备份恢复并重放删除清单
- **THEN** 有效数据和资料可访问，已删除会话内容不会重新可访问

#### Scenario: 保留清理

- **WHEN** 执行事件、用量及对象清理
- **THEN** 到期可清理对象按策略移除，仍被有效运行或回滚版本引用的资料保留

### Requirement: 兼容且可安装分发

对外桌面产物 MUST 完成正式分发签名、公证和安装启动验收，核对图标、中文显示名、appId、用户目录和 ASCII 名称；官网必须提供对应有效版本，受支持客户端契约兼容。

#### Scenario: 正式安装

- **WHEN** 下载正式发行的 DMG 或 ZIP 并安装启动
- **THEN** 签名公证及启动检查通过，图标和产品标识正确

#### Scenario: 官网与兼容性

- **WHEN** 从官网取得发行包并连接服务
- **THEN** 下载版本匹配发行记录，受支持旧客户端的公开接口和事件仍可消费
