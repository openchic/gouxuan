## Purpose

在桌面设置中为管理员提供受权限保护的知识库入口，经专用文件选择和平台服务完成上传、审核、阶段重试、评测、发布与回滚，并在页面离开后保留服务端任务进度而不开放通用本地文件权限。

## ADDED Requirements

### Requirement: 知识库界面预览

界面阶段 MUST 明确标记示例资料，允许筛选、查看详情和填写上传表单，但不授予真实管理员权限或伪造上传、审核、发布与回滚结果。原生选择只返回文件元数据，不暴露本地路径。

资料状态 MUST 使用紧凑筛选栏，可与名称搜索组合筛选；无匹配项时显示空态并提供清除筛选。

资料列表的操作按钮 MUST 完整显示文字并保留可点击区域。已确认原操作列固定为 66px，扣除单元格内边距后不足以容纳按钮，导致“查看”文字截断；操作列宽度 MUST 同时容纳单元格内边距和完整按钮。

#### Scenario: 查看资料操作

- **WHEN** 用户查看知识库列表
- **THEN** “查看”按钮文字完整，点击后可打开对应资料详情

#### Scenario: 组合筛选

- **WHEN** 用户选择资料状态并输入名称关键词
- **THEN** 列表只显示同时符合条件的资料，清除筛选后恢复全部示例资料

#### Scenario: 选择本地资料

- **WHEN** 用户在预览表单选择 PDF 或 Markdown
- **THEN** 展示名称和大小，取消不改变已有选择，超过 20MB 或不支持的文件被拒绝，服务未接入时上传明确不可用

### Requirement: 管理员菜单与路由

知识库菜单及路由 MUST 仅对管理员开放，直接访问路由也检查角色，服务端仍独立校验所有管理请求。

#### Scenario: 管理员进入

- **WHEN** 管理员打开设置中的知识库
- **THEN** 可看到资料、任务与可执行操作

#### Scenario: 普通用户进入

- **WHEN** 普通用户手动访问知识库路径
- **THEN** 入口被拒绝，不能执行上传或发布

### Requirement: 受限文件上传和任务查看

资料上传 MUST 通过专用原生文件选择与同一认证请求入口，页面不获得任意文件读取或存储直连权限；轮询仅在页面需要时运行，关闭页面不取消服务端任务。

#### Scenario: 选择文件

- **WHEN** 管理员通过上传按钮选择支持文件
- **THEN** 只上传明确选择的文件并返回可恢复任务状态

#### Scenario: 离开页面

- **WHEN** 任务执行中离开知识库页
- **THEN** 停止界面轮询，重新进入可继续查看原任务

### Requirement: 审核重试与发布操作

客户端 MUST 显示解析预览、原文定位、失败原因与阶段操作，显式审核及重试使用服务端确认结果；仅有效评测后的候选可显式发布，冲突与回滚结果清晰显示。

#### Scenario: 失败阶段重试

- **WHEN** 管理员重试任务失败阶段
- **THEN** 恢复相应任务并展示服务端确认状态，不重复确认产物

#### Scenario: 发布冲突

- **WHEN** 另一管理员已发布新版本
- **THEN** 显示重新生成候选并评测的要求，不把冲突显示为成功
