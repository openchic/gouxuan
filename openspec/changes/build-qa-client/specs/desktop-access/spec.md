## Purpose

让桌面客户端通过受限进程桥接访问平台服务，在同一认证边界管理登录、请求和流式连接，保护凭据和账号数据，并以持久的浅色、深色及跟随系统偏好统一页面与原生外观。

## ADDED Requirements

### Requirement: 窗口内容与拖动区域

客户端 MUST 移除显示应用名和界面预览文字的全局顶部栏及其布局占位，保留原生系统窗口按钮。macOS 的侧栏内容 MUST 避让窗口按钮，并提供不占布局高度的透明拖动区域，不能遮挡页面按钮和输入；其他平台不增加额外避让空间。

#### Scenario: 顶部栏移除后使用窗口

- **WHEN** 用户进入问答、设置或登录页面
- **THEN** 页面不显示全局顶部栏，系统窗口按钮保持可用，macOS 可从顶部空白区域拖动窗口，页面导航和输入正常

### Requirement: React 目录与样式归属

React 页面目录 MUST 与主组件同名，界面页面与组件 MUST 使用 `index.tsx` 与同目录 `index.css`，并直接引入自己的样式；页面私有组件与 hooks 留在所属页面，共享样式由共享组件持有。根 CSS 只包含主题、reset 和基础规则，无独立界面的 Provider 与路由适配组件不创建空样式文件。

#### Scenario: 独立进入页面

- **WHEN** 用户直接进入登录、问答、通用设置或知识库路由并打开页面弹层
- **THEN** 页面与弹层的布局和样式完整，不依赖其他页面曾经加载，其主题及现有交互保持有效

### Requirement: 问答侧栏底部入口

未登录问答工作台的侧栏底部 MUST 使用紧凑的一行布局，左侧为文字登录按钮，右侧为仅显示齿轮图标的设置按钮；左右内容与会话列表的内边距对齐，不为未使用的底部行保留空白。设置入口保留可访问名称、键盘焦点、提示和原有点击区域。

#### Scenario: 从底部进入页面

- **WHEN** 用户点击左侧登录按钮或右侧齿轮按钮
- **THEN** 分别进入登录或设置路由，窗口会话内的问答草稿保留

### Requirement: 独立设置布局

设置 MUST 使用左侧菜单、右侧具体页面的两栏布局，提供通用设置与有权限的知识库入口；进入设置时替换问答侧栏，不叠加会话导航或横向设置标签。左侧顶部仅保留返回问答入口，不展示设置标题或保留其空白占位；右侧页面保留自身标题。通用设置的关于区域 MUST 只展示产品名称和版本号。菜单项目间距和行高 MUST 与会话列表一致。

#### Scenario: 设置内切换页面

- **WHEN** 用户打开设置并选择知识库或通用设置
- **THEN** 左侧菜单保持可见并标记当前页面，右侧内容随路由切换，前后导航有效

#### Scenario: 返回问答

- **WHEN** 用户从设置返回问答工作台
- **THEN** 恢复问答两栏布局，保留本次窗口会话内的草稿及已保存主题

### Requirement: 预览登录与本地外观

界面预览 MUST 提供登录表单但不伪造认证成功或持久保存密码；登录页 MUST 使用居中单列布局，品牌与表单保持同一视觉焦点，字段保留可见标签，窄屏及低高度窗口可访问全部内容。错误反馈 MUST 保持表单布局稳定，密码可见切换保持有效；“先看看工作台”预览入口 MUST 仅在开发模式显示，生产构建不渲染链接、箭头或布局占位，认证错误不引导用户访问隐藏入口。客户端的三态主题通过受限桥接保存在本地，并统一覆盖登录页、工作台、弹层和原生窗口。

#### Scenario: 服务尚未接入

- **WHEN** 用户填写合法登录信息并提交
- **THEN** 明确提示认证服务尚未接入，不创建账号会话或保存密码

#### Scenario: 开发模式预览入口

- **WHEN** 用户在开发模式打开登录页
- **THEN** 显示“先看看工作台”链接与箭头，可进入原有工作台预览；登录服务尚未接入时可继续提示预览

#### Scenario: 生产登录页入口

- **WHEN** 用户在生产构建打开登录页
- **THEN** 不渲染工作台预览链接、箭头或占位，认证服务尚未接入时只提示暂时无法登录，不引导预览；字段、密码切换、错误反馈及主题保持有效

#### Scenario: 预览偏好恢复

- **WHEN** 用户修改工作台主题并重启客户端
- **THEN** 恢复该主题偏好，进入登录页时页面与原生界面继续使用相同主题

#### Scenario: 登录页试用回钩 logo

- **WHEN** 用户在浅色或深色外观下打开登录页
- **THEN** 登录标题上方显示用户选定的尖端回钩矢量标记，保留细尖起笔与向内收尖的轮廓，不显示原「玄」字色块或概念稿背景；图标自身在浅深色外观下均使用主题主色 `#1b1b1b` 图形与白色底，登录页原有背景继续随主题适配；原有居中单列布局、字段标签、密码切换、错误反馈及开发模式下的工作台预览入口保持有效
- **AND** 图形不重复朗读标题或增加键盘焦点，试用不改变问答助手头像及应用分发图标

#### Scenario: 登录页使用最新图标

- **WHEN** 应用 SVG 母版更新后用户打开登录页
- **THEN** 直接引用最新应用 SVG 母版，沿用其中的轮廓、画布、比例、白底及左移 30px 的光学校正；不得重复保存路径、另算补偿位移或用 CSS 再次平移
- **AND** 保持登录页图标外框尺寸、圆角、页面背景、主题及布局和交互不变，不修改应用资源或菜单栏独立模板

#### Scenario: 浅色背景上的图标边界

- **WHEN** 白色图标底板与浅色登录页背景接近，导致底板边界不明显
- **THEN** 仅通过主题令牌细描边增强底板与页面背景的分离，不添加阴影，描边不占布局空间或改变 SVG 内容尺寸；图标保持最新母版的 `#1b1b1b` 主体与纯白底板，不通过改色、再次位移或修改页面背景解决
- **AND** 描边随主题适配，图标原有尺寸、圆角、页面布局和交互保持不变，应用及菜单栏资源保持不变

### Requirement: 单一业务请求与受限桥接

桌面业务 HTTP、事件连接和资料上传 MUST 统一经受限原生运行层发起，页面只调用类型化白名单，参数和事件进行运行时校验；不提供自定义模型或通用文件与数据库访问。

#### Scenario: 页面提交

- **WHEN** 页面调用问答方法
- **THEN** 通过白名单请求平台服务，页面不能取得令牌或直接连接模型

#### Scenario: 非法调用来源或参数

- **WHEN** 不可信页面或错误参数调用桥接
- **THEN** 拒绝执行并返回结构化错误

### Requirement: 凭据与认证续期

客户端 MUST 保护刷新凭据、仅在运行内存使用访问凭据，合并并发续期并识别迟到旧令牌错误；登录和续期自身不递归触发刷新。

#### Scenario: 并发过期

- **WHEN** 多个保护请求同时需要续期
- **THEN** 共用一个续期操作，迟到旧 401 不重复刷新

#### Scenario: 凭据隔离

- **WHEN** 页面、缓存或日志被检查
- **THEN** 不包含明文登录凭据或模型密钥

### Requirement: 有限认证重放与业务错误

客户端 MUST 对认证后的可重建请求最多重放一次并保留原幂等键，不盲目重发网络结果不明的写请求；网络异常、403 或 429 不触发退出，确定会话失效才合并通知。

#### Scenario: 认证重放

- **WHEN** 提交因访问令牌过期而续期成功
- **THEN** 至多重放一次且使用原幂等键，不重复创建运行

#### Scenario: 网络暂时失败

- **WHEN** 续期或普通请求网络失败
- **THEN** 保留登录状态并显示可识别错误，不反复弹窗或跳转

### Requirement: 登录代次与账号隔离

退出或切换账号 MUST 停止旧请求与订阅并拒绝迟到结果，保护新账号缓存和路由；确定失效的登录代次只能通知一次。

#### Scenario: 迟到续期

- **WHEN** 旧账号续期结果在退出或切换后返回
- **THEN** 不恢复旧登录，不写入新账号状态

#### Scenario: 重复失效通知

- **WHEN** 多个请求同时发现设备会话吊销
- **THEN** 产生一次有效登录变化和路由处理

### Requirement: 三态主题和偏好恢复

客户端 MUST 提供浅色、深色和跟随系统，默认跟随系统；切换即时生效、离线可修改，偏好持久保存并在登录前后保持有效，重启和账号切换正确恢复。

#### Scenario: 固定模式

- **WHEN** 用户选择浅色或深色后系统外观变化
- **THEN** 界面保持用户选择，不随系统变化

#### Scenario: 跟随系统

- **WHEN** 用户选择跟随系统并改变系统外观
- **THEN** 页面和原生界面自动更新，无需重启

#### Scenario: 启动与账号切换

- **WHEN** 重启或切换到另一个账号
- **THEN** 加载对应偏好，启动无明显错误主题闪烁，草稿及运行不被主题切换破坏

### Requirement: 导航和资源安全

客户端 MUST 仅加载受信页面及平台服务，阻止任意导航、新窗口和远程脚本；引用及 Markdown 资源受授权与白名单限制，主题覆盖弹层、原生控件和自定义语义颜色。

#### Scenario: 不可信资源

- **WHEN** 回答包含未知远程图片或链接
- **THEN** 不自动向任意地址发请求或打开不可信页面

#### Scenario: 主题弹层

- **WHEN** 切换深色后打开来源弹层和原生控件
- **THEN** 文字、背景、状态和控件与当前主题一致且可读
